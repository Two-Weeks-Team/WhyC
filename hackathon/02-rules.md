## SUBMISSION REQUIREMENTS

### What to Build
> "Build a functional agent — powered by **Gemini** and **Google Cloud Agent Builder** — that integrates a Partner Entity's MCP server to solve a real challenge."

### Partner Track Options
- Arize
- Elastic
- Fivetran

(Pick exactly one track per submission.)

### Team Composition
- Individual or team — **maximum 4 people**
- All members must be eligible
- One designated **Representative** for team submissions

### Platform Requirements
> "A submitted Project must run on at least one of the following platforms: **web, Android, or iOS**"

### Technology Restrictions (CRITICAL)
- **Must use** Google Cloud services and the relevant Partner's products
- Quote: *"The use of other services that directly compete with Google Cloud (for cloud platform capabilities) or with the Partner whose track you've selected is not permitted"*
- AI usage limited to **Google Cloud AI tools** and Partner's built-in AI features

> ⚠️ This excludes AWS Bedrock / OpenAI / Anthropic API as the **agent backbone**. Gemini is the model. Cloud Run / Vertex AI are the runtime.

### Originality
> "Projects must be newly created by the entrant during the Contest Period. The Project must be Your original creation not a modification or extension of Your or anyone else's existing work"

### Multiple Submissions
- Individuals may submit multiple unique submissions
- If winning multiple prizes, Google may allocate per track
- A submission can win at most one prize

## SUBMISSION COMPONENTS (Required Deliverables)

### 1. Code Repository
- Public URL with complete source code
- Must include **open-source license file** (visible in About section)
- Contains all assets and functional instructions

### 2. Hosted Project
- URL for judging and testing
- Must function consistently as described

### 3. Text Description
- Summary of features and functionality
- Technologies used
- Data sources
- Findings and learnings

### 4. Demonstration Video
- **Maximum 3 minutes** (only first 3 minutes evaluated)
- Shows project functioning on intended platform(s)
- Uploaded to **YouTube or Vimeo**
- **English or English subtitles required**
- Original, unpublished work
- Cannot contain third-party advertising, logos, sponsorship indicators
- Cannot violate third-party publicity, privacy, or IP rights
- No derogatory / offensive / sexual / profane / discriminatory content

## JUDGING

### Stage One — Pass/Fail
Submission must:
- Include all required components
- Reasonably address the challenge
- Apply Partner data and Google Cloud products effectively
- (Automated tools may be used)

### Stage Two — Scored (equal-weighted)
1. **Technological Implementation** — *"Does the interaction with Google Cloud and Partner services demonstrate quality software development?"*
2. **Design** — *"Is the user experience and design of the project well thought out?"*
3. **Potential Impact** — *"How big of an impact could the project have on the target communities?"*
4. **Quality of the Idea** — *"How creative and unique is the project?"*

### Timeline
- Judging period: **June 22 – July 6, 2026**
- Winners notified: ~**July 7, 2026**
- Winner response deadline: 2 business days from notification

### Tie-Breaking
Criterion scores compared in listed order; if still tied, judges vote.
